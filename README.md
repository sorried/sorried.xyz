# sorried.xyz

Личная страница Maya Moon в стиле профиля GitHub: боковой профиль, README, стек и четыре репозитория. Системный шрифт без засечек, компактная сетка, светлая и тёмная темы, часы UTC+5. HTML, CSS и JavaScript без зависимостей. Основное содержимое доступно без JavaScript.

## запуск

Нужен Node.js 22 или новее. Установка пакетов не требуется.

```sh
npm run dev
```

Открыть http://127.0.0.1:5173. Другой порт: `PORT=8080 npm run dev`.

```sh
npm run check
npm run build
npm test
npm run preview
```

`dist/` содержит готовый статический сайт. Его можно разместить на статическом хостинге. Канонический адрес в метаданных: https://sorried.xyz/.

## редактирование

- `index.html`: био, проекты, ссылки и метаданные.
- `styles.css`: оформление, адаптивная сетка и темы.
- `main.js`: сохранение темы и местное время.
- `assets/avatar.jpg`: локальная копия аватара GitHub.
- `docs/design.md`: референсы и проверенные источники.

Сайт не запрашивает GitHub API при посещении. Тема хранится в localStorage; при недоступном хранилище переключение продолжает работать.

## проверка

`npm test` проверяет выбор и сохранение темы, работу при заблокированном хранилище, часовой пояс, HTTP-ответы собранной страницы и её ресурсов, внутренние якоря, запрет доступа к служебным файлам и неподдерживаемые методы.

Дополнительно проверено в установленном headless Chromium через Playwright на ширинах 320, 375, 430, 768, 960 и 1280 px. На всех ширинах нет горизонтального переполнения; до 768 px профиль и основное содержимое идут в одну колонку, от 768 px располагаются рядом. Проверены переключение темы, сохранение после перезагрузки и отсутствие ошибок JavaScript. Основное содержимое также проверено с отключённым JavaScript.

Скриншоты: [телефон, 375 px](docs/previews/mobile.png), [десктоп, 1280 px](docs/previews/desktop.png). Мобильная версия проверена эмуляцией, а не на физическом телефоне. Проверка не добавляла зависимостей в проект.
