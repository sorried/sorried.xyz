# sorried.xyz

Личная страница Maya Moon: обо мне, проекты, инструменты и контакты. Русский язык, светлая и тёмная темы, часы UTC+5. HTML, CSS и JavaScript без зависимостей. Основное содержимое доступно без JavaScript.

## запуск

Нужен Node.js 22 или новее. Установка пакетов не требуется.

```sh
npm run dev
```

Открыть http://127.0.0.1:5173. Другой порт: `PORT=8080 npm run dev`.

```sh
npm run check
npm run build
npm test
npm run preview
```

`dist/` содержит готовый статический сайт. Его можно разместить на статическом хостинге. Канонический адрес в метаданных: https://sorried.xyz/.

## редактирование

- `index.html`: био, проекты, ссылки и метаданные.
- `styles.css`: оформление, адаптивная сетка и темы.
- `main.js`: сохранение темы и местное время.
- `assets/avatar.jpg`: локальная копия аватара GitHub.
- `docs/design.md`: референсы и проверенные источники.

Сайт не запрашивает GitHub API при посещении. Тема хранится в localStorage; при недоступном хранилище переключение продолжает работать.

## проверка

`npm test` проверяет выбор и сохранение темы, работу при заблокированном хранилище, часовой пояс, HTTP-ответы собранной страницы и её ресурсов, внутренние якоря, запрет доступа к служебным файлам и неподдерживаемые методы.

Визуальная проверка в браузере в этой сессии не выполнена: инструмент управления браузером вернул пустой список доступных браузеров. Адаптивность и клавиатурную навигацию нужно дополнительно проверить в браузере.
