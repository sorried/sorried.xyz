# sorried.xyz

Личная страница в акварельном стиле. Визуальный ориентир: [Painted в Posy](https://github.com/Himanshu-Sangshetti/posy). Код написан заново по превью дизайна, без переноса исходного кода и графики Posy. HTML, CSS и JavaScript без внешних зависимостей. Шрифты и изображения хранятся локально.

## запуск

Нужен Node.js 22 или новее. Устанавливать пакеты не требуется.

```sh
npm run dev
```

Открой [локальное превью](http://127.0.0.1:5173). После правки файлов обнови страницу в браузере.

```sh
npm run check
npm run build
npm run preview
```

`build` собирает статические файлы в `dist/` и записывает заголовок, описание и Open Graph из `content.js` в HTML. Для публикации загрузи содержимое `dist/` на свой статический хостинг. Сервер превью нужен только для локальной проверки. `dev` и `preview` используют один порт, запускай их по очереди.

## своё содержимое

Все тексты и ссылки находятся в `content.js`:

| поле | что заменить |
| --- | --- |
| `url`, `title`, `description` | адрес сайта, заголовок вкладки и описание для поиска |
| `profile` | имя, путь к аватарке, описание и подпись |
| `socials` | ссылки на соцсети; можно добавить или удалить элементы |
| `note` | короткая записка |
| `photo` | картинка, её описание и подпись |
| `section` | заголовок над проектами |
| `featured` | основной проект, его картинка и ссылка |
| `links` | остальные ссылки; можно добавить или удалить элементы |
| `footer` | подпись внизу |

Свои изображения положи в `assets/` и укажи путь в `content.js`. Ссылки в примере ведут на GitHub владельца этого репозитория. Никакие адреса Telegram или почты не предполагаются.

Доступные значки для `icon`: `github`, `code`, `mail`, `telegram`, `link`. Для почты используй `mailto:you@example.com`. Поле `label` у соцсети отображается рядом со значком. Ссылки открываются в новой вкладке, почта открывается в почтовом приложении.

Фон страницы задан в `styles.css` как `assets/sky.webp`. Цвета и шрифты находятся в начале этого файла, в `:root`. Аватарка по умолчанию: `assets/avatar.svg`. Картинка с котом: `assets/window.webp`.

Часы всегда показывают время Екатеринбурга, `Asia/Yekaterinburg`, UTC+5, независимо от часового пояса посетителя. Кнопка «поделиться» копирует `url` из `content.js`; если доступ к буферу обмена закрыт, показывает адрес текстом. Иллюстрацию можно открыть крупнее, закрыть кнопкой, клавишей Escape или нажатием за пределами картинки.
