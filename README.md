# sorried.xyz

Личная страница Maya Moon. Чёрный фон, зелёный акцент, локальные Manrope и Unbounded. Био, стек, четыре проекта и контакты. Референс: [deco9er.github.io](https://github.com/deco9er/deco9er.github.io).

## запуск

Нужен Node.js 22 или новее. Для сайта установка пакетов не требуется.

```sh
npm run dev
```

Открыть http://127.0.0.1:5173. Другой порт: `PORT=5174 npm run dev`.

```sh
npm run check
npm run build
npm test
npm run preview
```

`dist/` содержит готовый статический сайт. Канонический адрес в метаданных: https://sorried.xyz/.

## редактирование

- `index.html`: био, проекты, контакты и метаданные.
- `styles.css`: типографика, цвета, мобильная версия.
- `main.js`: тема, активный раздел, копирование Telegram, часы UTC+5.
- `assets/`: аватар, favicon и локальные шрифты с лицензиями.
- `docs/design.md`: референс и источники биографии.

Тёмная тема включена по умолчанию. Выбранная тема сохраняется в localStorage. При заблокированном хранилище переключение работает. Основное содержимое, ссылки и раскрытие списка инструментов доступны без JavaScript.

## проверка

`npm test` проверяет тему, заблокированное хранилище, часовой пояс, HTTP-ответы, ресурсы и внутренние якоря.

`npm run test:browser` запускает браузерные проверки, если Playwright и Chromium уже доступны в окружении. Можно передать путь к установленному модулю и браузеру:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/path/to/chrome npm run test:browser -- /path/to/playwright/index.mjs
```

Проверены ширины 320, 375, 430, 768, 960 и 1280 px: отсутствие горизонтального переполнения, переходы навигации и выбранный раздел, кликабельная строка проекта, переход в Telegram, копирование ника, раскрытие инструментов и сохранение темы. Внешние переходы проверяются с перехватом страницы назначения. Доставка сообщений в Telegram не проверяется. Есть отдельная проверка с отключённым JavaScript.

Скриншоты: [телефон](docs/previews/mobile.png), [десктоп](docs/previews/desktop.png). Мобильная версия проверена эмуляцией в Chromium. Для обновления скриншотов браузерному тесту можно передать переменную `PREVIEW_DIR` с папкой назначения.
