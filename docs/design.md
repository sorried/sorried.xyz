# sorried.xyz

Минималистичная личная страница на русском. Статический HTML, CSS и небольшой JavaScript без зависимостей. Содержимое читается без JavaScript.

## направление

Тёплый белый фон, угольный текст, терракотовый акцент. Крупный serif-заголовок, спокойный системный sans-serif в тексте, моноширинные подписи. Узкая колонка, секции с полями слева, проекты строками. Светлая и тёмная темы, доступная клавиатурная навигация, мобильная версия.
