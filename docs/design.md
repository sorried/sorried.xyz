# sorried.xyz

Компактная личная страница на русском по структуре профиля GitHub. Статический HTML, CSS и небольшой JavaScript без зависимостей. Содержимое читается без JavaScript.

## направление

Референс: https://github.com/sorried. Слева аватар, имя, био и контакты; справа README, инструменты и репозитории. Системный sans-serif на всей странице, основной текст 14–16 px. Нейтральные поверхности GitHub, синие ссылки, тонкие рамки, небольшие радиусы. Без serif, большого приветственного экрана и нумерации секций.

Сначала мобильная версия: одна колонка, поля 16 px, компактный профиль с аватаром рядом с именем. От 768 px: профиль слева, контент справа. Репозитории в две колонки только при достаточной ширине правой части. Длинные названия переносятся. Светлая и тёмная темы, клавиатурная навигация, поддержка уменьшения движения.
