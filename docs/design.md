# sorried.xyz

Личная страница на русском. HTML, CSS и небольшой JavaScript без зависимостей приложения.

## направление

Выбранное пользователем направление: личная страница с артом, цветом и небольшими деталями. Палитра опирается на изображения из публичного профиля: лаванда, кремовый, тёмный сливовый и рыжий акцент. Крупный рекламный ник и пустые колонки убраны.

В начале обычное представление и большой арт. На телефонах изображение стоит над текстом, сохраняя естественные пропорции. Второй арт сопровождает короткую заметку о dnb. Проекты собраны плотнее, в две колонки на широком экране; плагины выделены лавандовым блоком. Manrope используется для основного текста, Unbounded только в названии сайта. Крупное изображение не поворачивается и не увеличивается сверх разрешения источника.

Светлая тема по умолчанию, тёмная тема с тёплым сливовым фоном включается кнопкой. Выбор сохраняется. Наведение, клавиатурный фокус и уменьшение движения поддерживаются. Содержимое доступно без JavaScript.

Навигация ведёт к секциям, отмечая текущий раздел при нажатии и прокрутке. Вся строка проекта является ссылкой. Внешние ссылки открываются в текущей вкладке. Копирование Telegram показывает результат; если буфер обмена недоступен, выводится ник для ручного копирования.
