# sorried.xyz

Личная страница на русском. HTML, CSS и небольшой JavaScript без зависимостей приложения.

## направление

Текущий референс пользователя: https://github.com/deco9er/deco9er.github.io. Просмотрен исходный index.html 15 ноября 2026. Предыдущий референс deco9er/bio-site отменён пользователем.

За основу взяты чёрный фон, зелёный акцент, Manrope и Unbounded, крупный ник, секции с заголовком слева и содержимым справа. Код страницы написан отдельно. Чужие изображения, видео и биография не переносятся.

Основной текст 15 px, контрастные заголовки, обычный курсор, заметные состояния наведения и фокуса. На телефонах секции в одну колонку. Содержимое и ссылки доступны без JavaScript. Тёмная тема по умолчанию; явный выбор светлой сохраняется.

Навигация ведёт к секциям, отмечая текущий раздел при нажатии и прокрутке. Вся строка проекта является ссылкой. Внешние ссылки открываются в текущей вкладке. Копирование Telegram показывает результат; если буфер обмена недоступен, выводится ник для ручного копирования.
